SMART PLAY

Universal router

  1. 1
    One-time Router Shortcut setup

    Buat satu Shortcut “iPBooster Play”, bukan satu Shortcut per game.

  2. 2
    If Shortcut Input → Open App

    Shortcut Input dipakai di aksi Jika. Setiap cabang Jika berisi Buka App dengan game yang dipilih langsung.

  3. 3
    Game Mode stays native

    Setelah game terbuka, Game Mode dan prioritas CPU/GPU tetap dikelola iOS.

No fake installed-app detection

Safari/PWA tidak boleh membaca daftar aplikasi yang terpasang. iPBooster hanya menampilkan kemampuan perangkat yang browser memang boleh baca, lalu memakai Shortcuts atau deep link yang sah untuk launch.
