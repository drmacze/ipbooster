SETUP RECIPE

Build the real shortcut

  1. 1
    Create “iPBooster Device Status”

    Buka Shortcuts dan buat shortcut dengan nama yang sama seperti field di atas.

  2. 2
    Read real device values

    Tambahkan aksi yang tersedia di iOS untuk Battery Level dan Network Details, lalu susun hasilnya menjadi Dictionary.

  3. 3
    Return JSON text

    Ubah Dictionary menjadi JSON/text dan jadikan itu output terakhir Shortcut. iPBooster akan menerima output melalui result callback.

  4. 4
    Create one launch Shortcut per game

    Di shortcut game: atur Gaming Focus / Low Power Mode / volume sesuai kebutuhan, lalu gunakan Open App untuk membuka game tersebut. Masukkan nama Shortcut itu saat menambahkan game.

System truth

Game Mode adalah fitur iOS dan aktif otomatis untuk game yang didukung. iPBooster tidak menampilkan tombol “force Game Mode” palsu. Launcher hanya menyiapkan hal yang memang bisa diotomasi, lalu menyerahkan prioritas CPU/GPU ke iOS.
